# Complaint Management System

A simple and effective web app to submit and manage complaints.

## Features
- Submit complaints with Name, Title, Description
- View all complaints
- Delete complaints

## Tech Stack
- Python + Flask
- HTML, CSS

## How to Run
1. pip install -r requirements.txt
2. python app.py
3. Open http://127.0.0.1:5000
